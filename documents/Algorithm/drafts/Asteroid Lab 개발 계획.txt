# 0. 프로젝트 정의

## 목표

`Asteroid Lab`은 Shapez2 asteroid mining optimization을 위한:

```text id="tbb55x"
Decode
→ Reconstruction
→ Placement Search
→ Routing
→ Validation
→ Replay Visualization
→ Optimization Lab
```

전체 통합 연구/개발 플랫폼이다.

단순 “배치기”가 아니라:

```text id="coco4h"
실시간 실험 가능한 Solver Research Platform
```

으로 설계한다.

# 최종 결론

현재 프로젝트 방향에서 가장 중요한 건:

```text id="b9v9bw"
"배치"와 "연결 가능성"을 분리하지 않는 것
```

이다.

기존 v1/v2의 핵심 붕괴 원인은:

```text id="0di09z"
placement 먼저
routing 나중
```

구조였다.

Asteroid Lab은 반드시:

```text id="ppwyf0"
placement candidate 생성 순간
즉시 exterior connectivity feasibility 평가
```

구조로 설계되어야 한다.
