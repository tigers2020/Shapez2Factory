# 0. Project Definition

## Goal

`Asteroid Lab` is an integrated research/development platform for Shapez2 asteroid mining optimization:

```text id="tbb55x"
Decode
→ Reconstruction
→ Placement Search
→ Routing
→ Validation
→ Replay Visualization
→ Optimization Lab
```

It is not a simple "placer" but is designed as:

```text id="coco4h"
A Solver Research Platform capable of real-time experimentation
```

---

# 1. Core Philosophy

## Top Priority Principle

```text id="ycbjp8"
Everything is provisional
until connected to exterior trunk.
```

That is:

```text id="sjem9c"
Until connected to exterior trunk,
all placements remain provisional
```
filecite turn0file2 L691-L739

---

## Absolute Prohibitions

### Prohibition 1 — Replay-based algorithms

```text id="xw3l3i"
NDJSON
Replay
solver_summary
```

Must not be used as algorithm inputs.

---

### Prohibition 2 — Pass-first rigid pipeline

The existing:

```text id="kx1d7v"
Pass1 → Pass2 → STEP4
```

tightly coupled structure is forbidden.

---

### Prohibition 3 — Routing deferred to later

Must always:

```text id="xtn27f"
placement candidate
+
route feasibility
```

be evaluated together.

```text id="b9v9bw"

```

The core collapse cause in existing v1/v2 was:

```text id="0di09z"

routing later
```

Asteroid Lab must be designed with:

