# Shapez 2: Stacker 입력 역할 (bottom / top)

## 주장(참고용)

위키 요약에 따르면 Stacker는 **top 입력**으로 받은 도형을 **bottom 입력** 도형 위에 쌓아 결과를 낸다고 설명된다.

```text
stacker(bottom_input, top_input) -> output
```

## 솔버·그래프 모델 권장

- 반드시 **bottom / top** 용어로 통일한다.
- **left / right** 로 모델링하면 포트·배선·수요 요약이 어긋나기 쉽다.

## 신뢰도

- 위키 **중간**. 게임 내 툴팁·실측으로 교차 확인 권장.
