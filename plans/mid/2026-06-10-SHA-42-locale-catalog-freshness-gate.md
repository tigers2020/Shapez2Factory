# Plan: CI locale catalog freshness gate

## Source Issue

- Linear: SHA-42
- Status at planning time: Todo
- Priority: Mid

## Problem

Korean locale catalogs are generated by `scripts/build_locale_ko.py` and committed under `locale/ko/LC_MESSAGES/` (`django.po`, `django.mo`, `djangojs.po`, `djangojs.mo`). GitHub Actions never regenerates these files or fails when they drift from current template/JS gettext sources. A PR can add or change `{% trans %}` / JS `gettext()` strings while leaving stale committed catalogs and still pass CI.

## Scope

- Add a pytest contract test that runs `python scripts/build_locale_ko.py` and asserts no diff under `locale/ko/LC_MESSAGES/*`.
- Wire the check into CI (new matrix task or fold into `test-fast`).
- Regenerate and commit current catalogs once the gate lands.
- Document the gate in `documents/ai/manuals/testing.md` § Locale if needed.

## Non-goals

- Translating missing KO strings (separate i18n backlog; see SHA-43).
- Replacing the polib-based builder with GNU gettext.
- Changing runtime Django locale middleware behavior.

## Implementation Plan

1. **Add contract test** — create `tests/unit/test_locale_catalog_freshness.py`:
   - Capture `git status --porcelain locale/ko/LC_MESSAGES/` (or hash the four files) before running builder.
   - Run `[sys.executable, "scripts/build_locale_ko.py"]` from repo root via `subprocess` (same pattern as `test_build_locale_ko_strict.py`).
   - Assert `git diff --quiet locale/ko/LC_MESSAGES/` (or equivalent: no changed paths under that directory).
   - On failure, include `git diff --stat locale/ko/LC_MESSAGES/` in assertion message so CI logs show drift.
   - Mark `@pytest.mark.unit` so `test-fast` picks it up.

2. **Verify test fails on current tree** — run `python scripts/build_locale_ko.py` locally; confirm `git diff --stat locale/` shows changes (msgids like `No runs yet`, `Paste a blueprint and run the solver.`, `Layer summaries appear after a solver run.`). Run new test before regen to confirm red.

3. **Regenerate committed catalogs** — run `python scripts/build_locale_ko.py` from repo root; commit all four files under `locale/ko/LC_MESSAGES/`.

4. **Confirm test green** — `pytest tests/unit/test_locale_catalog_freshness.py -v` passes with regenerated catalogs.

5. **CI wiring (if needed)** — `.github/workflows/ci.yml` matrix `test-fast` already runs `pytest -m "unit and not slow"`. No CI change required if the new test is unit-marked. If the test is slow or needs isolation, add a dedicated matrix task (e.g. `locale-freshness`) following existing `validate` job pattern.

6. **Update testing manual** — extend `documents/ai/manuals/testing.md` § Locale (~line 298) to state that CI enforces committed `.po`/`.mo` freshness via `tests/unit/test_locale_catalog_freshness.py`, distinct from `--strict` KO-dict completeness (`test_build_locale_ko_strict.py`).

7. **Commit** — separate commits for test, catalog regen, and docs if preferred.
